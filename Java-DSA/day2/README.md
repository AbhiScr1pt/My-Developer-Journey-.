**Operations:**
- Addition
- Subtraction
- Multiplication
- Division
- Modulo

**Concepts Used:** Scanner, Switch-Case, Arithmetic Operators

### 2. Find Month Name
Created a program that takes a month number as input and displays the corresponding month name.

**Concepts Used:** Scanner, Switch-Case

### 3. Age Checker
Created a program to check whether a person is an adult or not based on their age.

**Logic:**
- Age greater than 17 → Adult
- Otherwise → Not Adult

**Concepts Used:** If-Else, Relational Operators

### 4. Find Greater Number
Created a program that compares two numbers and checks whether they are equal or which number is greater.

**Logic:**
- If both numbers are equal → Equal
- If first number is greater → A is greater
- Otherwise → A is smaller than B

**Concepts Used:** If-Else, Nested If-Else, Relational Operators

### 5. Odd-Even Checker
Created a program to check whether a given number is even or odd.

**Logic:**
- Remainder 0 when divided by 2 → Even
- Otherwise → Odd

**Concepts Used:** If-Else, Modulo Operator
