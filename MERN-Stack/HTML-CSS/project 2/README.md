# 🐼 Kung Fu Panda – Landing Page

A simple Kung Fu Panda themed webpage created using HTML and CSS. This project focuses on practicing webpage structure, background images, CSS positioning, and basic styling.

Built as part of my web development learning journey.

## 📸 Project Overview

The webpage includes:

- A background image on the left section.
- A Kung Fu Panda heading.
- A descriptive paragraph.
- A Read More button.
- Custom text colors and positioning.

## 🛠️ Technologies Used

- HTML5 – For webpage structure and content.
- CSS3 – For styling, background images, and positioning.

## 💡 CSS Concepts Practiced

- Universal selector (`*`)
- Margin and padding reset
- Box sizing (`box-sizing`)
- Width and height
- Background image
- Background size (`cover`)
- Background position (`center`)
- Absolute positioning
- Font size and font weight
- Text colors
- Border radius

## 🎯 What I Learned

- Practicing HTML and CSS together.
