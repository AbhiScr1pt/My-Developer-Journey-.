# 🎮 Clutch-Zone – Gaming Landing Page

Clutch-Zone is a simple gaming-themed landing page created using HTML and CSS. It introduces a gaming platform through a background image, dark overlay, heading, descriptive text, and an entry button.

This project was built as part of my journey to learn web development and practice HTML and CSS fundamentals.

## 📸 Project Overview

The webpage features:
- A full-screen gaming background image.
- A dark transparent overlay for better text visibility.
- A centered content section.
- A Clutch-Zone heading with letter spacing.
- An introductory paragraph about the gaming platform.
- An "Enter ClutchZone" button.

## 🛠️ Technologies Used

- HTML5 – For webpage structure and content.
- CSS3 – For styling, layout, positioning, and background effects.

## 💡 CSS Concepts Practiced

- Universal selector (`*`)
- Box sizing (`box-sizing`)
- Background image and positioning
- Background size (`cover`)
- Transparent backgrounds using RGBA
- Absolute positioning
- CSS transform and translate
- Margins, border radius, and letter spacing
- Font styling
